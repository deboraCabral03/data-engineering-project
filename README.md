Data Engineering Project

An end-to-end data engineering project developed to practice and demonstrate data extraction, transformation, validation, storage, and analysis using Python, SQL, Oracle Database, and Power BI.

Project Overview

This project simulates a business data environment involving clients, contracts, financial transactions, and operational data.

The goal is to build a structured data pipeline, from data extraction to analytical reporting, applying data engineering concepts and good development practices.

Learning Objectives

Extract data from REST APIs.

Transform and validate data using Python.

Design relational database structures.

Write SQL queries and PL/SQL procedures.

Develop data loading and integration processes.

Build analytical reports using Power BI.

Apply version control and documentation practices.
